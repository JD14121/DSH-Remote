2. Product goal
The phone is a chat client, not a remote terminal.
The architecture is:
Phone
  = Chat Client

PC
  = DSH Server

Secure Remote Transport
  = R9 responsibility

Remote Gateway
  = stable application protocol boundary

DSH
  = agent runtime
The desired remote experience is:
Android phone
→ GPT-like DSH Remote UI
→ secure remote transport
→ PC Gateway
→ supervised DSH
Do not turn the product into:
SSH terminal UI
remote desktop
shell console
generic PC control app
SSH or an overlay network may be used as transport infrastructure, but they must remain invisible implementation details beneath the chat client.
