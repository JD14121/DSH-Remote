HOW TO USE THIS BACKUP
----------------------
1. Mount this encrypted volume.
2. Copy the ACME/accounts/... tree into a lego storage root, preserving the paths.
3. Confirm recovery read-only:

       lego accounts list --path <restored-root> --json

   Expect keyType EC256, the production directory URL, status valid, and
   accountURL https://acme-v02.api.letsencrypt.org/acme/acct/3780342786

   lego v5.3.1 stores the account URL under registration.accountURL, NOT
   registration.uri.

4. Verify the key is the right one by deriving the public key fingerprint:

       openssl pkey -in 1300637954@qq.com.key -pubout -outform DER | openssl dgst -sha256

   Expected SHA-256 (SPKI):
       2f3d3328b5e7b9cd4c04465e3b7aa53f71d7733a7c60d96244068c316978bb63

   If that fingerprint matches, this is the live account's key.

DO NOT
------
- Do not register a second ACME account.
- Do not create a certificate order as part of a recovery test.
- Do not copy this material to the VPS. The VPS must never hold the ACME account
  key, which is what prevents it from obtaining a browser-trusted certificate on
  its own.
- Do not place this material in the Git repository or in any Docker image.
